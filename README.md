# asteroide-no-espaco

Clone de Asteroids em HTML5 Canvas. Jogue direto no navegador, no celular ou PC.

## Jogar

**Online:** https://detillimichel-max.github.io/asteroide-no-espaco/

Ou abra o arquivo `index.html` localmente.

## Controles

**Celular:**
- Botões esquerda/direita giram a nave
- Botão inferior direito acelera
- Botão superior direito atira

**PC:**
- ← → gira
- ↑ acelera
- Espaço atira

## Como funciona

- Nave com inércia e wrap na tela
- Asteroides se quebram em pedaços menores
- 3 vidas, score e high score salvos
- Controles afastados da borda para mobile

## Tecnologias

- HTML5 Canvas
- JavaScript puro
- Sem dependências externas
